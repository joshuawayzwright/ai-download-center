Best AI coding assistants: 15 tools and models, grouped by where you use them

The AI coding tools in the AI Download Center catalog fall into four groups: assistants in your editor (GitHub Copilot, Cursor, Cline), agents you run in the terminal (Claude Code, Gemini CLI, Codex CLI, Aider), autonomous agents you host yourself (OpenHands), and the models behind them. Six of the nine assistants and agents are open source, GitHub Copilot and Cursor have free plans, and every entry links straight to its official site or repository.

This list isn't ranked, and we haven't benchmarked these tools. It groups them by where they fit in your workflow, so you can pick a tool first and then choose a model to run behind it.

In your editor

GitHub Copilot

What it's for: An AI pair programmer for VS Code, Visual Studio, JetBrains IDEs, Vim and Neovim.

Who it suits: Developers who want AI help inside the editor they already use, including people outside VS Code.

Price type: Freemium. The catalog notes a free plan, and GitHub's page describes "GitHub Copilot Free" with limited functionality and "No credit card required."

FreemiumOfficial site

Cursor

What it's for: An AI-powered code editor with built-in coding agents.

Who it suits: Developers who are happy to switch to a new editor built around AI, rather than adding an extension to their current one.

Price type: Freemium, with a free Hobby plan. Cursor's pricing page lists it as "No credit card required" with "Limited Agent requests."

FreemiumOfficial site

Cline

What it's for: An open-source autonomous coding agent for VS Code and JetBrains, also available as a CLI.

Who it suits: Developers who want an agent that works through tasks in their editor, from open-source code they can inspect. Cline's site describes it as "Apache 2.0 open source" and lists JetBrains support as Early Access.

Open sourceOfficial site

Continue (no longer maintained)

What it's for: An open-source coding assistant for VS Code and JetBrains.

Status: No longer maintained after joining Cursor. The final 2.0.0 release stays available under Apache 2.0, and the GitHub repository is now read-only.

Who it suits: People already using it, or anyone who wants to fork or study the code. If you're starting fresh, look at the maintained tools above.

Open sourceOfficial repository

In the terminal

Claude Code

What it's for: Anthropic's coding agent for the terminal, IDEs and web.

Who it suits: Developers who already have a paid Claude plan, or who want to pay per use through API credits.

Price type: Paid. It's included with paid Claude plans or can be used with API credits.

PaidOfficial site

Gemini CLI

What it's for: Google's open-source AI agent that brings Gemini into your terminal.

Who it suits: Developers who want to try a terminal agent without paying. Sign in with a Google account to use the free tier. The GitHub README lists the free tier as "60 requests/min and 1,000 requests/day" for personal Google accounts.

Open source (Apache 2.0)Official repository

Codex CLI

What it's for: OpenAI's open-source coding agent that runs locally in your terminal.

Who it suits: Developers who want OpenAI's coding agent working on files on their own machine.

Open source (Apache 2.0)Official repository

Aider

What it's for: A terminal-based AI coding assistant for local workflows and code changes across repositories.

Who it suits: Developers who work with git. Aider's site says it "automatically commits changes with sensible commit messages" and can "connect to almost any LLM, including local models."

Open sourceOfficial site

Autonomous agents

OpenHands

What it's for: An open-source coding agent for autonomous task execution and local development automation.

Who it suits: Developers and teams who want to hand off whole tasks and run the agent on their own infrastructure. The README calls it a "self-hosted developer control center for coding agents and automations," with a Docker sandbox option, and says you can "use with any LLM."

Price type: Open source (MIT license, per the GitHub repository)

Open sourceOfficial repository

Chat assistants

If you just want to paste in code and talk it through, the catalog also tags Claude (Anthropic, Freemium) for coding. It's a long-context AI assistant for writing, coding, planning and careful reasoning. Unlike the tools above, it works in a chat window and doesn't edit your files directly.

The models behind them

Several of these tools, including Aider, OpenHands and Cline, let you choose the model. The catalog tags these models for coding.

Hosted models

  • Claude Opus 5.5 (Anthropic, Paid): Anthropic's most capable model for complex reasoning, long-context analysis and agentic coding.
  • GPT-5.5 (OpenAI, Paid): the previous-generation OpenAI flagship for coding, agents and production workloads.

Open models

  • Qwen3 (Alibaba Cloud, Open source): a multilingual open model family for reasoning, chat, coding and agents.
  • DeepSeek Coder (DeepSeek, Open source): a code-specialized model focused on generation, debugging and engineering tasks.
  • Code Llama (Meta, Open source): a code-fine-tuned model family for generation, refactoring and technical tasks.

To run an open model on your own machine, see our guide to local LLM apps. Which models a tool supports, and what hardware a model needs, depends on both. Check each official page before you set anything up.

How to choose

  • Want AI inside the editor you already use? Start with GitHub Copilot or Cline.
  • Open to a new editor built around AI? Look at Cursor.
  • Prefer the terminal? Try Gemini CLI (free tier with a Google account), Codex CLI or Aider. If you already pay for Claude, Claude Code is included.
  • Want to hand off a whole task on your own infrastructure? Look at OpenHands.
  • Want to keep code on your own machine? Pair an open-source tool that accepts local models, like Aider or OpenHands, with an open model like Qwen3, DeepSeek Coder or Code Llama.
