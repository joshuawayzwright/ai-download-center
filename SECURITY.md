# Security Policy

## Supported versions

This project is maintained as a static GitHub Pages site. The latest branch is the supported version for security updates.

## Reporting a vulnerability

Please do not open a public GitHub issue for security problems.

Instead, send a private report via GitHub Security Advisories:

- Go to the repository's Security tab
- Select "Report a vulnerability"
- Provide a clear description, reproduction steps, and impact assessment

If you cannot use GitHub Security Advisories, email the maintainer through the GitHub profile and include the repository name.

## Response expectations

We aim to acknowledge valid reports promptly and assess fixes as quickly as practical. Please allow reasonable time for triage and remediation before sharing details publicly.
