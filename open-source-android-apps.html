How to choose

  • Starting from scratch? Install F-Droid or Droid-ify first, then find the rest there.
  • Most worried about privacy? Signal for messages, FairEmail for email, Aegis for logins.
  • Replacing Google Photos? Immich backs up to a server you run yourself.
  • Want updates without an app store? Obtainium installs releases straight from each project.
