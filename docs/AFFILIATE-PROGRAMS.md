# Affiliate programs for catalog tools

These programs were checked on 19 November 2026 against each vendor's own affiliate page or terms, or the network page the vendor links to. Terms change often, sometimes without notice, so recheck each page before you sign up or quote a rate. The site owner must sign up personally: each program needs its own account, tax forms (such as a W-8BEN or W-9), and payout details, and none of that can be done on the owner's behalf. Where a rate or cookie length is not stated on an official page, this file says "not public" or "not stated". A listing here does not mean the site will be accepted. Most programs review each application.

Tool names in the first column match the names in `data/tools.json`.

## How to add a link to the site

1. Apply to the program from the sign-up page above and wait for approval.
2. After approval, copy your personal tracking link from the program dashboard.
3. Run:

   ```bash
   node scripts/set-affiliate.mjs "<Tool name exactly as in the catalog>" "<https tracking link>"
   node scripts/validate-catalog.mjs
   ```

4. Commit the change.

To remove a link, run `node scripts/set-affiliate.mjs "<Tool name exactly as in the catalog>" --remove`, then validate and commit as above.

Most programs require a visible affiliate disclosure on pages that carry tracking links. Check each program's terms for its wording and brand-use rules (several ban bidding on the brand name in paid search).
